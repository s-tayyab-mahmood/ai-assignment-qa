# FI-04: Locator drift (self-healing exercise)

**Status:** executed 2026-11-25 on GitHub Actions (workflow_dispatch, grep `@AE-18`). Branch kept unmerged; net change zero.

## Purpose
Show that the self-healing agent (`tools/heal`, `skills/self-healing.md`) heals a stale locator **safely**: it finds the right element on the page, proves the fix, and hands a patch to a human instead of changing code itself.

## Injected change
Branch `fi-04-locator-drift`, created from the branch that contains the agent. One line in `src/pages/CatalogPages.ts` (product details page, used by AE-18):
```diff
-    this.reviewHeading = page.getByRole('link', { name: 'Write Your Review' });
+    this.reviewHeading = page.getByRole('link', { name: 'Write a Review' });
```
This is the same situation as a UI rename: the test looks for text that is not on the page, while the page shows the real control under another name. We cannot change the public site, so the drift is injected on the test side. The product is unchanged.

## Expected behaviour
| Stage | Expected |
|---|---|
| Tests | AE-18 fails: `getByRole('link', { name: 'Write a Review' })` – element(s) not found. All other tests pass. |
| RCA | `LOCATOR_OR_UI_CHANGE` (≈ 50–60 %). The changed page object is not in the failure's stack, so RCA sees a missing element with clean network. |
| Self-healing | **Proposed, LOCATOR, found by rules:** the page snapshot has a link "Write Your Review" (closest match, well ahead of any other link). Patch changes the literal back; proof: type check, lint, AE-18 3/3 green. |
| Human | Reviews the patch and the screenshot, applies it on the branch with `git apply`, pushes; the branch run is green. |

## Procedure
1. Create the branch from the agent branch and inject the change (patch `fi-04-inject`). Push.
2. Actions → *Playwright QA + AI RCA* → **Run workflow** on `fi-04-locator-drift`, grep `@AE-18`.
3. Open the run's job summary: RCA section, then **Self-healing agent**. Download the `qa-report-…` artifact: `reports/heal/patches/*.patch`, `heal-report.json`, `audit-log.jsonl`.
4. Review the patch, apply it on the branch (`git apply <patch>`), commit, push, run again with grep `@AE-18` → green.
5. Close the branch without merging (the net change is zero).
